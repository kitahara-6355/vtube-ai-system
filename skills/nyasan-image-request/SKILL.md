# 足りないキャラ画像を作って登録する

画像生成は定額プランの Gemini アプリで行う。定額枠には API がないので、生成ボタンを押すのは人。それ以外（指示文づくり・台帳登録・動画への反映）は自動。

## どのアカウントで作るか
| 時期 | アカウント | 目安の枠 |
|---|---|---|
| プロトタイプ期（リリース前） | 個人の Google AI Pro | 画像 1日100枚前後（5時間ごと回復・週上限あり）、Flow 月1,000＋毎日50クレジット |
| リリース後の運用 | 弊社 Business Standard | Nano Banana Pro 月30枚、Flow 毎日50クレジット |

素材を使い回す設計なので、運用期の生成は1日0〜1枚の想定。表情集はプロトタイプ期に AI Pro でまとめて作る。

## 手順（2026-11-20 実測で確定。5枚中4枚が1回目で合格）
1. `python tools/manga.py prep episodes/<回>.json` で足りない絵（`need`）を洗い出し、共有ドライブの「絵づくり台帳（Gemini）」に1行1枚で足す。台帳は Claude が指示文と合否を書く場所。Gemini には添付しない（台帳経由だと「描くもの」が効かず別の絵になる。Drive リンクの参照画像も読めない）。
2. 北原さんに、チャットの中でそのまま貼れる形で渡す: **新しいチャット → 参照画像を Drive から1枚だけ添付 → 指示文を直接貼る**。
   - 参照画像は1枚だけ。複数添付するとポーズや頭身が混ざる（3枚添付で別ポーズ・3頭身になった）。
   - 立ち姿・全身は `直立ポーズ.png`、座ってマウスを使う絵は `パソコン操作中ポーズ.png`。
   - 指示文の型: 「添付した画像と同じキャラクター「よちよち社長」を、同じ画風で1枚描いてください。／描くもの: …／条件: 顔・服装・髪型・色・主線の太さ・頭身（2頭身）は添付画像と完全に同じ。胸の名札は添付画像のまま。正方形、無地の白背景、キャラを画面の中央に置き、全体が画面に収まる。文字や記号は入れない。」
   - 本番は法人アカウント（試作は個人可）。保存はスクショでなく絵の本体を `00_受付（ここに入れる）` へ。ファイル名は Gemini のままでよい（作成時刻で見分ける）。
3. Claude が判定する: 機械（正方形・白背景・はみ出し・記号）＋目で見る5項目（髪型・眉と目・服とタオル・頭身・主線）。参照画像と並べて見る。やり直しは最大3回。結果は台帳の同じ行へ（列ずれに注意: G=指示文）。
4. 合格した絵を `assets/library.json` に1行足す（`driveId` は 00_受付のファイル ID のままでよい）。画像は Drive API（環境変数 `AVS_DRIVE_ORGANIZER_TOKEN_JSON`）で `assets/img/<ID>.png` に落とす。MCP で1枚ずつ落とすより安い。
5. `render` と `sheet` で書き出し直し、**コマ一覧で余白を必ず目で見る**。
   - パソコン操作中ポーズを参照にした絵は右寄り・下切れになり、机や椅子も入るので、`crop: "bust"` だと頭の幅が机まで広がって社長が小さく写る（2026-11-20 北原さん指摘「余白がありすぎる」）。
   - その絵の `need` には `"crop": [0.0, 0.02, 1.0, 0.98]`（絵全体の高さで切る）を入れる。手元（マウス）が切れていないことも確かめる。
6. 代役が 0 コマになったら、`out/<回>/` の動画・コマ一覧・flow 画像を共有フォルダ `nyasan/<回>/manga/` に上書きする。

## 品質の基準（採用するか決めるとき）
- 服・髪・色・主線の太さが参照画像と同じ（違う絵柄は `library.json` の `excluded` に理由付きで記録して使わない）
- 背景は無地の白（自動切り抜きのため）。影や床があると切り抜きが崩れる
- 文字やロゴが崩れて入っていない

## まだ足りない素材（2026-10-28 時点）
- 背景（事務所の壁・デスク周り）。今はツールが描く仮の背景
- 社長のリアル寄り（キリっと系）の表情。`SH_REAL_SHY` 1枚のみ
